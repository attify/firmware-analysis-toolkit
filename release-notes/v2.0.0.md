# FAT 2.0.0

FAT 2.0 is the first regular release of the Rust-based Firmware Analysis Toolkit.
It brings firmware identification, extraction, binary and filesystem analysis, and emulation workflows into the `fat` command-line interface.

## Highlights

- **Identify unknown firmware:** recognize containers, compressed data, raw MCU images, and repeated regions before choosing an analysis workflow.
- **Inspect Cortex-M firmware:** recover vector tables, address mappings, startup paths, referenced strings, and decoded peripheral accesses, with profile-backed device-family information.
- **Explore binaries and filesystems:** inspect ELF files, trace data flow, map startup behavior, and search extracted firmware.
- **Work through a firmware project:** create a project, extract its files, analyze it, and prepare QEMU-based emulation with explicit backend prerequisites.
- **Read focused reports:** compact summaries, semantic colors, bordered tables, `--details` for supporting tables, and JSON for structured output.
- **Install versioned runtime data:** ship the matching profiles and helper resources with the executable and verify their contents with `fat data verify`.

## Installation

Choose the binary archive matching your platform from the assets below, verify it against `SHA256SUMS`, and extract it.
Keep `bin` and `share` together, then run:

```bash
./bin/fat --version
./bin/fat data verify
./bin/fat doctor
./bin/fat identify ./firmware.bin
```

The release also provides a runtime-data ZIP for Cargo installations and tagged source archives.
See the [installation guide](https://github.com/attify/firmware-analysis-toolkit/blob/v2.0.0/INSTALL.md) for source installation and external analysis tools.

## Upgrading from FAT 1.x

FAT 2 uses a new Rust CLI and project workflow.
Install it separately from FAT 1.x and follow the current installation guide; the older `setup.sh`, `fat.py`, and `fat.config` instructions apply to FAT 1.x.
Keep existing FAT 1.x workspaces and recreate the projects you need with `fat new ./firmware.bin`.
